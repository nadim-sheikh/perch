# OpenBuddy

A free, open-source AI buddy that lives next to your cursor on macOS. It sees
your screen, listens when you hold a key, answers out loud, and points at things.

Bring your own Anthropic or OpenAI API key. No account, no paywall, no telemetry.

## Use it

1. Build: `./build.sh` (needs Xcode / Swift 5.10+). The app lands in `~/Applications/OpenBuddy.app`.
2. Open it. A cursor icon appears in the menu bar.
3. In **Settings → AI**, paste your API key.
4. Grant Microphone, Speech, Screen Recording and Accessibility when asked
   (then quit and reopen once).
5. **Hold Control + Option and talk.** Let go to send. Or use **Ask by typing…**.
